# LINK Italia — Branch corso

Questa branch è dedicata allo sviluppo del corso e-learning LINK Italia e resta separata dalla pubblicazione del sito su `gh-pages`.

## Regola
- `gh-pages` = sito pubblico/demo verificato.
- `corso` = corso master, materiali didattici, script, slide, quiz, traduzioni, asset, export LMS/SCORM.
- Nessun materiale del corso viene pubblicato automaticamente sul sito.
- Nessuna credenziale o chiave API nel repository.

## Obiettivo
Creare un Corso Master indipendente dalla piattaforma, revisionato dalla Presidente/autrice, da esportare successivamente per FORMED/Moodle o altra piattaforma LMS europea.

## Lingue previste
- Italiano
- English
- Français
- Deutsch
- Español

## Output possibili
- video MP4
- slide
- PDF/dispense
- sottotitoli
- quiz/test
- pacchetto SCORM se richiesto
- asset H5P se utile
- materiali per caricamento manuale su Moodle/LMS
