# LINK FX LAB — 2400

Branch sperimentale separata da gh-pages e corso.

- 40 famiglie di effetti, 60 varianti parametrizzate per famiglia.
- Codici stabili FX-0001…FX-2400.
- Filtro, ricerca, anteprima, link diretto, copia codice.
- Caricamento progressivo per evitare di inserire 2400 schede nel DOM contemporaneamente.
- Riferimento LINK Italia: bersaglio, freccia, anelli, network canvas, marquee, popup e reveal osservati nella Home gh-pages.
- AIR: riferimento estetico dichiarato dall'utente; non è stata verificata una sorgente AIR in questo aggiornamento.

## Nota tecnica
Le 2400 voci sono combinazioni parametriche di 40 meccaniche visive, **non** 2400 algoritmi indipendenti. Alcune famiglie mostrano prototipi hover, non implementazioni complete di accessibilità e comportamento di produzione. Non incorporare direttamente il laboratorio nel sito pubblico senza selezione e rifinitura.
